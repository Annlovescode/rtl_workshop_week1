# [RISC-V Processor Design and Verification Workshop](https://www.vlsisystemdesign.com/riscv-processor-design-workshop/)

Welcome to the **RISC-V Workshop**, a practical series focused on understanding RISC-V architecture, designing processors, and verifying functionality using open-source tools. This repository is structured into multiple days, each with its own practical labs, code, and explanations.

## About This Workshop  

This workshop is designed for students, researchers, and engineers who want to:  

- Explore the RISC-V instruction set architecture (ISA)  
- Learn how to design a simple RISC-V processor in Verilog  
- Perform simulation and debugging using open-source tools  
- Understand pipelining, hazards, and control logic in processors  
- Verify RTL with testbenches and instruction traces  

---

## Prerequisites  

- Basic knowledge of computer architecture (ISA, datapath, control)  
- Familiarity with Verilog/SystemVerilog basics  
- A Linux environment (or WSL for Windows/macOS)  
- Installed tools: `iverilog`, `gtkwave`, `yosys`, `riscv-gcc`, and `spike` simulator

## Workshop Structure  

The workshop is organized day by day, each with its own folder and README:  

- [Day 1: Introduction to RISC-V ISA and Toolchain Setup](Day_1/README.md)  
- [Day 2: Datapath and Control Unit Design in Verilog](Day_2/README.md)  
- [Day 3: Implementing ALU, Register File, and Memory Interfaces](Day_3/README.md)  
- [Day 4: Pipelining and Hazard Handling](Day_4/README.md)  
- [Day 5: Verification, Debugging, and Performance Analysis](Day_5/README.md)  

Each day’s README includes:  
- Concept explanations with diagrams  
- Hands-on labs with Verilog code and testbenches  
- Step-by-step instructions for running simulations  
- Debugging tips and design insights
